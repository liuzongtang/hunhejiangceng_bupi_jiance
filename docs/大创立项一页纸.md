# 织瑕智鉴——基于 RT-DETR 与七维混合奖惩的织物瑕疵智能检测系统

**大学生创新创业训练计划（大创）立项 · 项目一页纸**

## 一句话定位

把「漏检断经 = 整匹报废、漏检毛粒 = 轻罚」的工业代价差异，**可微地写进检测器的训练目标**，并用系统化诊断把关键缺陷的召回瓶颈从「玄学调参」变成「可定位、可验证、可兜底」。

## 背景与痛点

纺织质检长期依赖人工目检，效率低、易漏检。现有深度学习检测器只优化平均精度，隐含「所有错误同等重要」的错误假设，导致断经、断氨纶等严重缺陷召回率低、告警易被静默降级——一旦漏检，整匹布报废。本项目直面这一「工业代价差异未纳入训练」的核心问题。

## 三大创新点

1. **七维混合奖惩（框架创新）**：将定位、分类、校准、漏检、误检及关键类敏感度（断经/断氨纶、星跳/死皱）7 个维度构造成对模型输出**可微**的奖励信号，首次把工业代价差异显式注入 RT-DETR 端到端训练目标；进一步以 GRPO（查询噪声强化学习 + 组内相对优势 + KL 锚定）探索「奖励引导的检测器训练」。
2. **双层天花板诊断（方法创新）**：用混淆矩阵「漏检 / 错分」分解 + 逐类阈值标定，系统定位关键类召回瓶颈为两层——视觉同源标签噪声（类合并召回 0.40→0.88）与细缺陷低置信度漏检（断氨纶 54 个实例仅 1 例错分、8 例漏检且 5 例低于阈值）；并通过**七种训练信号的严格 A/B 消融**，证明瓶颈在特征级判别力而非训练信号，给出 DETR 一对一匹配「专家策略」的可验证机理解释；据此提出**代价敏感 objectness 头**（标定层干预），首次在 B 口径拿到正向标定结果（4% 误报率下有无瑕疵召回 1%→48%）。
3. **部署层安全兜底（工程创新）**：逐类成本敏感阈值 + 告警层易混淆类升级策略，实现「检测—告警—停机」闭环，关键缺陷召回 0.57→0.91，从系统层面杜绝严重缺陷被静默降级。

## 技术路线

```
RT-DETR-L 检测器（18 类，PyTorch/ONNX 双后端）
   → 七维可微奖励注入（Layer-1）+ GRPO 强化学习（Layer-3）
   → 双层天花板诊断（混淆矩阵 + 阈值标定 + 七负消融 + 代价敏感 objectness 头）
   → 逐类成本敏感阈值 + 告警层升级兜底
   → FastAPI + WebSocket 实时告警 + 中文看板 + 边缘部署
```

## 关键数据

| 指标 | 数值 |
|---|---|

## 预期成果

- 一套可复现的织物瑕疵智能检测系统（4 推理后端 + ONNX 边缘部署 + 实时告警）；
- 学术论文 1 篇（已形成论文骨架 v0.3）；
- 软件著作权 / 专利（可选）；
- 一份可迁移的「工业代价导向训练 + 系统化诊断」方法论，可推广至其它细粒度长尾质检场景。
