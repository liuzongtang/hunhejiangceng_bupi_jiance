# 研究内容与目标

## 一、拟解决的关键问题

围绕"织物瑕疵智能检测"这一主题，本项目拟解决四个层层递进的关键问题：

**问题一：如何将工业代价差异纳入检测器的训练目标。** 传统检测器以分类与回归损失为唯一优化目标，隐含假设"所有错误同等重要"。但在纺织质检中，漏检一个断经（严重缺陷，导致整匹布报废）与漏检一个毛粒（轻微缺陷）的工业代价相差悬殊。如何在训练目标中显式编码这种代价差异，使模型优先学会识别高代价缺陷，是本项目要解决的第一个关键问题。

**问题二：如何在不牺牲总体精度的前提下提升关键缺陷召回。** 直接对关键类加权或注入奖励，往往以精确率下降、总体 mAP 持平为代价——本项目实测将漏检注入奖励后，召回率 +0.030 但精确率 -0.022、mAP50 基本持平；进一步对分类损失加权（Direction B）、box 损失加权（R2）、甚至把 IoU 换成 NWD 损失几何（R3）均不敌均匀微调对照。如何在"召回—精度"权衡中取得更优解，而非简单的指标搬移，是本项目的第二个关键问题。

**问题三：如何区分"模型可训练差距"与"双层天花板"。** 本项目发现，断经召回约 0.45 的瓶颈并非类别稀有度（同为稀有类的断氨纶表现良好），而是两层：第一层为断经↔磨痕、纬缩↔粗纬等视觉同源类的双向混淆（标签噪声）；第二层为合并后关键类仍低于阈值漏检——混淆矩阵显示断氨纶 0 错分、133 漏检，是"检不到"而非"分错"。如何系统化地诊断并界定这两层天花板，避免在错误方向上投入无效的训练干预，是本项目的第三个关键问题。

**问题四：如何在"检测—告警"闭环中提供安全兜底。** 即使模型无法完全区分视觉同源类，产线也不能因此停机错误或漏停。如何在告警层对易混淆类进行保守升级，避免严重缺陷被静默降级为轻微告警，是本项目的第四个关键问题。

## 二、主要内容

**（一）20 类 Tianchi 织物瑕疵检测器。** 基于 RT-DETR-L 构建端到端检测模型，覆盖破洞、污渍、断经、断氨纶等 20 类瑕疵；输入 1280 拉伸方图、一对一匈牙利匹配、免 NMS，输出 `(1, 300, 6)` 的归一化 `[cx, cy, w, h, score, class]`；支持 PyTorch 与 ONNX 双推理后端，便于边缘部署。

**（二）七维混合奖惩机制。** 将定位（D01）、分类（D02）、校准（D03）、漏检（D04）、误检（D05）及关键类敏感度（D06 断经/断氨纶、D07 星跳/死皱）七个维度构造为对 logits 与边界框**可微**的奖励信号，形成 `L_total = L_det + β·L_scalar + γ·L_consistency`，实现"工业代价导向"的训练目标。

**（三）奖励注入与 GRPO 训练路线。** 两条互补路线：Layer-1 将可微奖励直接注入 ultralytics RT-DETR 训练循环（`loss_reward = -β·mean(R)`），实现零侵入的监督增强；Layer-3 以查询噪声 REINFORCE + 组内相对优势 + KL 锚定，探索奖励引导的强化学习训练，并解决 RT-DETR 内容查询被 detach 导致均值梯度无法回传的问题。在此基础上，进一步系统消融分类严重度加权（Direction B）、box 损失加权（R2）与 NWD 损失几何（R3），以七种干预的严格 A/B 对照界定"训练信号"路径的边界。

**（四）双层诊断与瓶颈定位。** 通过逐类 mAP 画像、混淆矩阵（漏检/错分分解）、双向性判定、裁剪图人工复核与逐类 P/R 阈值标定，定位两层天花板：视觉同源类的标签噪声（断经↔磨痕、纬缩↔粗纬）与细缺陷的低置信度漏检（断氨纶 0 错分、133 漏检），量化"合并收益"与"降阈值召回—精确率权衡"，输出合并/重标注与逐类阈值建议。

**（五）告警兜底与系统集成。** 设计 `effective_alert_severity()` 升级策略（`CONFUSABLE_HIGHER_IMPACT` 映射），构建 FastAPI 后端 + WebSocket 实时告警 + 中文看板 + 产线模拟器的完整系统，并支持 ONNX 边缘部署。

## 三、核心目标

**总目标：** 构建一套基于 RT-DETR 与七维混合奖惩、面向 20 类织物瑕疵的端到端智能检测系统，在保证总体检测精度的同时，显著提升关键缺陷的召回与告警可靠性。

**具体目标（可量化）：**

1. **检测精度**：20 类 mAP50 ≥ 0.59，并给出逐类精度画像，明确关键类的定位与差距；
2. **奖励机制**：七维奖励对模型参数可微，奖励注入与 GRPO 训练给出严格的 A/B 对照结论；
3. **诊断方法**：形成"混淆矩阵 + 双向性判定 + 裁剪复核"的标签噪声诊断流程，输出可执行的合并/重标注建议；
4. **系统落地**：4 种推理后端 + ONNX 边缘部署 + 实时告警 + 中文看板，通过全部功能与单元测试（≥ 205 项）。

## 四、重要观点

**观点一：检测器的优化目标应反映工业代价，而非仅最小化平均误差。** 七维混合奖惩将"漏检/误检/关键类敏感度"等代价项落为可微的损失分量，使训练目标与生产目标对齐，是对"平均精度最大化"这一传统范式的重要补充。

**观点二：关键缺陷的召回瓶颈是"双层天花板"，而非模型可训练差距。** 第一层为视觉同源、双向混淆的标签噪声（类合并可修复，召回 0.40→0.88）；第二层为细缺陷的低置信度漏检——本项目七种训练信号干预（奖励注入、GRPO、分类加权、box 加权、NWD 损失几何）均不敌均匀微调，证明低置信度是困难定位的忠实反映而非校准失误。对此应转向特征层（SPDConv 等保留细缺陷特征）、标定层（objectness 头）或部署层（逐类阈值）解决，而非继续堆训练技巧。

**观点三："检测—告警"必须闭环设计安全兜底。** 在模型无法完全区分易混淆类的前提下，告警层应"宁可信其有"——将疑似高影响类的低影响类告警升级为疑似严重缺陷，从系统层面杜绝关键缺陷被静默降级的风险，这是工业质检系统可靠性的底线要求。
