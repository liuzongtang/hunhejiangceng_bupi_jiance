# B1 族检测器探针 —— 预注册

- **臂**：`b1_family3_s42`
- **协议**：从 `runs/rtdetr/tianchi18_mosaic1280/weights/best.pt` 换头 18→3（`enc_score_head` / `dec_score_head` / `denoising_class_embed` 重铸，框头不变，其余权重原样搬运），在 `data/tianchi_family3` 上按从头训配方微调 20 epoch（MuSGD auto / lr0 5e-4 / bf16 / rect / batch 4 / imgsz 1280 / workers 4 / seed 42）。
- **唯一变量**：类别数与标签粒度（18 类 → 3 族）。框、图像、划分完全不变（val 仍是 957 图 / 953 框）。
- **对照**：把 18 类预测按同一份 3 族映射聚合后再算的 3 族 AP。
- **判据（开跑前写死）**：专用族检测器的族级 **AP@0.5 比"18 类聚合"高 ≥ 0.02** → 族级子问题有头量 → 才启动 B2 级联；否则阶段 B 关闭。
- **诚实的前置判断（已在 PREREG 写明）**：本轮 P0.1 实测 18 类 GT 级错分仅 **5/953（0.52%）**，类别轴基本没有头量；族级探针的价值只剩"降类别数能否提升框/召回"这一支。因此本臂**优先级最低**，即使转正预期收益也有限。
- **失败转向**：族级 AP 不升 → 阶段 B 关闭，算力全部留给 M1/D1/C1 的种子确认。
- **种子计划**：42（单种子探针，不用于显著性）。
- **预计时长**：3.5–4 h（20 epoch）。
- **额外观测（不作判据）**：每族召回、A↔C 跨族互混是否如论文 4.10 所述（族内错误集中）。
