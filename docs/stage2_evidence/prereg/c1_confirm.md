# C1 confirm（三种子 + 配对对照）—— 预注册

## 触发依据

C1 screen（seed 42）官方口径 **mean = 0.6490 vs B\* 0.6208 = +0.0281**，超过 screen 门
（B\*+0.005 = 0.6258）**5.6 倍**，也超过种子离散度（0.0093）3 倍。
逐类分解显示这不是均匀抬升，而是**容量再分配**：12 类上涨、5 类下跌。
上涨集中在稀有类（dense_section +0.179 / hanging_warp +0.078 / stain +0.063 / hole +0.060 /
size_stain +0.061），下跌集中在三个大类（weft_shrink −0.053 / three_silk −0.044 /
broken_warp −0.040 @AP0.5）。AP@0.1/0.3/0.5 **三个口径同时上升**（+0.030/+0.029/+0.025），
不是 PR 曲线滑动。
sanity：官方 mAP50 0.6056 vs results.csv 峰值 0.6028，差 0.0028 ≤ 0.004（F6 通过）。

## 判据（开跑前写死）

1. **每个种子的配对差** `Δ_s = mean(arm_s) − mean(control_s)`，s ∈ {123, 2024}；
2. **转正**（CONFIRMED_POSITIVE）= 两个配对差都 > **+0.005**，且
   三个种子的臂平均（含 seed 42 的 0.6490 与其对照 B\* 0.6208）> 对照平均 + 0.005；
3. **部分阳性**（PARTIAL）= 两个配对差都 > 0 但至少一个 ≤ +0.005；
4. **阴性**（NEGATIVE）= 任一配对差 ≤ 0，或配对差均值 ≤ 0.005；
5. 任一臂的 crit_recall（hole/broken_warp/broken_spandex 的 R@maxF1 均值）**低于同种子对照**
   → 记录为"以关键类召回换 mean"，即使 mean 达标也要在结论里标注。

## 已知风险（诚实记录）

- C1 的优势部分来自**大类掉点换稀有类涨点**。若 confirm 复现，结论应写成
  "早期奖励把容量向稀有类再分配，从而提升 mean mAP"，而**不是**"整体检测变强"。
- broken_warp 在 AP@0.5 上掉了 0.040（虽然 AP@0.1 +0.023、R@F1 +0.005）。若 confirm 里
  broken_warp 的 AP@0.5 继续下滑，需在论文里单独讨论"薄框类定位变松"。
- 本批不跑 B2 级联；B1 族探针排在最后（3.5 h），它的前置假设（分类轴）已被 P0.1 否定。
