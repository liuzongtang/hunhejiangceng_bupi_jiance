# 01 · 核心思路：为什么要七维奖惩

## 1. 问题：传统检测损失"看不见"工业代价

RT-DETR 的原生训练损失由三部分组成（分类 focal/vfl + 回归 GIoU/L1 + 去噪辅助），它的数学形式是：

```
L_det = Σ (分类误差 + 回归误差)
```

这个形式有一个隐含假设：**每个样本、每一类的误差是等价的**。梯度只关心"平均误差变小"，不关心"错在哪一类、错成什么"。

但在织物质检里，错误的代价是不对称的：

| 错误 | 工业后果 | 代价 |
|---|---|---|
| 漏检断经 | 整匹布带病入库、甚至断经拉伤织机 | 极高 |
| 漏检毛粒 | 外观瑕疵，可降级/返修 | 低 |
| 把磨痕误判成断经 | 触发停机，产线虚惊 | 中（比漏检好） |

所以一个"mAP 高"的模型，可能恰好把最致命的断经漏掉了。**优化目标与生产目标不对齐，是我们要解决的核心矛盾。**

## 2. 思路：把"代价"写成"可微的奖励"

我们不改变检测器结构，只改造**训练目标**。做法分三步：

**第一步：定义奖励。** 把"我们期望模型表现出的行为"拆成 7 个可量化的维度（详见 [02-七维定义与可微化](02-七维定义与可微化.md)）：

```
D01 定位精准度   D02 分类准确度   D03 置信度校准
D04 漏检惩罚     D05 误检惩罚
D06 断经/断氨纶敏感度   D07 星跳/死皱敏感度
```

**第二步：可微化。** 奖励要能反向传播进模型，就必须对模型的 `logits` 和 `boxes` 可导。所有硬判决（`argmax`、`.item()`、硬 IoU 阈值）都换成软版本（softmax 概率质量、sigmoid 软指示）。这是整个模块的技术核心，也是它与"在损失里硬加权"的本质区别。

**第三步：折进总损失。** 把 7 维奖励聚合成一个标量 `R_scalar`，以 `-R_scalar`（最大化奖励）的形式并入总损失：

```
L_total = L_detection + β · L_scalar + γ · L_consistency
```

## 3. 三大设计原则

### 原则一：可微性（否则奖励只是"打分器"，不是"训练器"）

奖励如果对模型参数不可导，就只能用来做 early-stopping 或挑模型，无法把梯度送进权重。本模块用三招保证可微：

| 硬判决 | 软替代 | 用处 |
|---|---|---|
| `argmax(logits)` | `softmax(logits)` 的质量 | D02 分类、D06/D07 敏感度 |
| `IoU > 0.5 ?` | `sigmoid((IoU - 0.5) / τ)` | D04 漏检、D05 误检 |
| 硬 IoU（标量） | 向量化可微 IoU | D01 定位 |

（具体公式见 [02](02-七维定义与可微化.md)。）

### 原则二：代价非对称

奖励的取值和权重是**故意不对称**的：

- 漏检 `lambda_miss=1.5` > 误检 `lambda_fp=1.0`：**漏检比误检更该罚**。
- 关键类（D06/D07）用 `3·p_crit - 2` 的映射，使"检测到=+1、漏掉=-2"：**漏检关键类的惩罚是普通类的 2 倍**。

### 原则三：分层训练，各自解决不同问题

奖励注入有两条互补路线（详见 [04](04-奖励注入与GRPO.md)）：

| 层 | 做法 | 解决的问题 |
|---|---|---|
| **Layer-1** | 把奖励项直接加进 RT-DETR 的监督损失 | 在"有监督"下给关键类召回加梯度 |
| **Layer-3** | GRPO：查询噪声采样 + 组内相对优势 | 探索"奖励引导的强化学习"，不依赖标注的探索温度 |

## 4. 模块的边界：它能做什么、不能做什么

**能做的：**
- 让"漏检关键类"产生更强的、有针对性的梯度。
- 提供一组 7 维的可观测信号，把训练过程"透明化"（每维一个数，方便诊断）。

**不能做的（本项目实测）：**
- 无法突破**标签噪声天花板**。断经↔磨痕、纬缩↔粗纬在图像层面就分不清，任何训练端干预都只是在"把指标从一类搬到另一类"。这类问题必须靠**数据合并**或**告警层兜底**（`effective_alert_severity()`）解决。

这个边界意识很重要：**七维奖惩是"锦上添花"，不是"包治百病"**。先诊断清楚是"模型学不会"还是"数据标不清"，再决定上不上奖励。
