# 02 · 七维定义与可微化

> 全部实现在一个文件里：`backend/training/dimension_rewards.py`。
> 核心类是 `DimensionRewardComputer`，入口是 `compute_all(predictions, targets) → Dict[name, scalar]`。

## 0. 输入约定

`compute_all` 吃两样东西：

- `predictions`: dict，至少含 `logits`（N,C）和 `boxes`（N,4，`[x,y,w,h]`）；可选 `confidences`、`classes`。
- `targets`: `List[Dict]`，每个含 `boxes`（M,4）和 `labels`（M,）。**单框检测器**约定每图一个主导框，所以下标 `i` 的预测直接对齐下标 `i` 的 GT。

> RT-DETR 场景下，`predictions` 的每行来自**匈牙利匹配后的 query↔GT 对**（见 [04](04-奖励注入与GRPO.md)），对齐已经由 matcher 完成。

## 1. 七个维度总表

| 维度 | 符号 | 公式 | 值域 | 可微化技巧 |
|---|---|---|---|---|
| D01 定位 | `R_loc` | `mean(2·IoU - 1)` | [-1, 1] | 向量化可微 IoU |
| D02 分类 | `R_cls` | `mean(2·p_true - 1)` | [-1, 1] | softmax/sigmoid 质量 |
| D03 校准 | `R_cal` | `-mean(|conf - p_true|)` | [-1, 0] | 置信度 vs 软准确度之差 |
| D04 漏检 | `R_miss` | `-λ_miss·mean(soft_miss)` | [-λ_miss, 0] | sigmoid 软漏检指示 |
| D05 误检 | `R_fp` | `-λ_fp·mean(conf·soft_fp)` | [-λ_fp, 0] | sigmoid 软误检指示 × 置信度 |
| D06 断经/断氨纶 | `R_broken` | `3·p_crit - 2`（仅关键类样本） | [-2, +1] | softmax 关键类质量 |
| D07 星跳/死皱 | `R_skip` | `3·p_crit - 2`（仅关键类样本） | [-2, +1] | softmax 关键类质量 |

维度索引常量：`DIM_LOC=0 … DIM_SKIP=6`，名字列表 `DIMENSION_NAMES = ["loc","cls","cal","miss","fp","broken","skip"]`。

## 2. 逐维展开（含代码位置）

### D01 定位：`compute_loc_reward`（`dimension_rewards.py` 第 238 行）

```
R_loc = mean( 2 · IoU(pred_i, gt_i) - 1 )
```

把 IoU ∈ [0,1] 线性映射到 [-1,1]：完全对齐 +1，完全没对齐 -1。

可微性来自 `differentiable_iou`（第 61 行）：用 `torch.maximum/minimum/clamp` 把交并比写成对 `pred_boxes` 可导的向量化运算，**不用** `.item()` 或硬 `if`。

### D02 分类：`compute_cls_reward`（第 259 行）

```
p_true_i = softmax(logits_i)[label_i]      # softmax 头
       或 = sigmoid(logits_i)[label_i]      # RT-DETR sigmoid 头
R_cls = mean( 2 · p_true_i - 1 )
```

用"GT 类别上的概率质量"替代 top-1 是否正确的硬判断——这是对准确率的**软代理**。`p_true` 越高，模型越"确信"正确类。

### D03 校准：`compute_cal_reward`（第 282 行）

```
R_cal = -mean( | conf_i - p_true_i | )
```

其中 `conf_i = max_c softmax(logits_i)_c`（模型自认为的置信度），`p_true_i` 是真实类别概率。校准好的模型"说多少分就是多少分"，两者差越小越好，所以永远 ≤ 0。它把"置信度是否可信"纳入了训练。

### D04 漏检：`compute_miss_reward`（第 306 行）

```
soft_miss_i = sigmoid( (iou_threshold - IoU_i) / tau )   # 0.5 / 0.1
R_miss = -lambda_miss · mean( soft_miss_i )               # lambda_miss = 1.5
```

关键思想：**IoU 低于阈值 → 软指示器接近 1 → 判为"漏检"→ 重罚**。`tau` 越小，这个 sigmoid 越接近硬阶跃；`tau=0.1` 保留梯度。漏检系数 1.5 > 误检系数 1.0，体现"漏检更致命"。

### D05 误检：`compute_fp_reward`（第 329 行）

```
soft_fp_i = 1 - sigmoid( (IoU_i - iou_threshold) / tau )
R_fp = -lambda_fp · mean( conf_i · soft_fp_i )           # lambda_fp = 1.0
```

"置信度很高却定位很差"的预测被重罚（`conf_i` 作为加权），惩罚"信心爆棚的乱报"。

### D06 / D07 关键类敏感度：`compute_broken_reward` / `compute_skip_reward`（第 356 / 364 行），共用 `_sensitivity_reward`（第 372 行）

```
p_crit_i = Σ_{c ∈ critical_set} softmax(logits_i)_c     # softmax 头：质量求和
       或 = max_{c ∈ critical_set} sigmoid(logits_i)_c   # sigmoid 头：取最大
reward_i = 3·p_crit_i - 2   若 label_i ∈ critical_set，否则 0
R = mean( reward_i )
```

映射 `3·p - 2` 把概率 p∈[0,1] 拉到 [-2,+1]：**关键类检测到了 +1，漏掉了 -2**——这是最重的一档惩罚。

关键类集合（当前 18 类方案，定义在 `backend/training/dataset.py` 第 37-38 行）：

```python
TIANCHI_BROKEN_CLASS_IDS = {9, 15}   # broken_warp(断经), broken_spandex(断氨纶)
TIANCHI_SKIP_CLASS_IDS   = {14, 17}  # star_skip(星跳), weave_defect(死皱/跳纱)
```

> 注意：项目从最初 20 类合并了两对视觉同源类（`surface_mark→broken_warp`、`coarse_weft→weft_shrink`），现在模型是 **18 类**（id 0..17）。完整类名见 `backend/schemas/defect.py` 的 `DefectType`。

## 3. 可微化技巧汇总（这是本模块的灵魂）

| 技巧 | 形式 | 为什么需要 |
|---|---|---|
| 向量化可微 IoU | `differentiable_iou` | 让定位奖励对 box 参数可导 |
| softmax 质量替代 argmax | `softmax(logits).gather(label)` | 让分类奖励对 logits 可导 |
| sigmoid 软指示替代硬阈值 | `sigmoid((thr - IoU)/tau)` | 让漏检/误检指示器可导 |
| 关键类质量替代类别集合判断 | softmax 关键类质量求和 | 让敏感度奖励可导 |
| 概率质量替代 top-1 准确率 | `p_true` | 让"分类正确"变成连续可导信号 |

## 4. head_type：softmax vs sigmoid

分类头归一化方式会影响 D02/D03/D06/D07 的概率计算，构造时必须选对：

- `head_type="softmax"`：单标签头（项目里的简易 `SimpleDefectDetector`），类间互斥，用 softmax。
- `head_type="sigmoid"`：**RT-DETR** 的逐类 focal/vfl 头，每个类是独立的二分类，用 sigmoid（第 154-156 行）。

> 用错 head_type 会让概率不是概率、梯度失真。RT-DETR 相关的奖励计算**一律 `head_type="sigmoid"`**。

## 5. 缺失数据时的兜底

`compute_*` 每个函数在拿不到对齐数据时返回一个"中性"标量（`loc/cls` 返回 -1，`cal/miss/fp/broken/skip` 返回 0），保证空 batch 不会崩。这些是常量 tensor（无梯度），只出现在边界情况。
