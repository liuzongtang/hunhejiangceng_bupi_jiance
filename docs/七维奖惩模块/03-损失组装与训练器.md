# 03 · 损失组装与训练器

> 实现：`backend/training/loss_functions.py`（损失组装）、`backend/training/hybrid_reward_trainer.py`（训练循环）。

## 1. 总损失公式

```
L_total = L_detection + β · L_scalar + γ · L_consistency
```

默认 `β=0.1`、`γ=0.05`。三项各司其职：

| 项 | 作用 | 实现 |
|---|---|---|
| `L_detection` | 传统检测损失：分类 CE + 回归 SmoothL1 | `detection_loss`（`loss_functions.py` 第 20 行） |
| `L_scalar` | 负标量奖励（最大化奖励） | `scalar_reward_loss`（第 70 行） |
| `L_consistency` | 七维"偏科"惩罚 | `consistency_loss`（第 107 行） |

## 2. 标量奖励的组装

`scalar_reward_loss` 先做两件事，再取负号当损失：

**（1）加权求和。** 把 7 维奖励按维度权重聚合：

```
R_scalar = Σ_k  softmax(w_k) · R_k
```

`dim_weights` 是一个**可学习的参数**（`nn.Parameter`，初始化 1/7），参与优化（见 [04](#4-可学习维度权重与自适应更新)）。用 `softmax` 归一化，保证权重和为 1。

**（2）加一致性奖励。** 再叠一个"维度越均衡越好"的奖励：

```
R_scalar += α · (-var(R))     # α = 0.3
```

方差小 → 各维度发展均衡 → 奖励更高。注意这与 `L_consistency`（第 3 节）是**两个不同的机制**：这里在"奖励"内部鼓励均衡，后者在"损失"层惩罚偏科。

最后 `L_scalar = -R_scalar`（因为要**最大化**奖励）。

## 3. 一致性损失

`consistency_loss`（第 107 行）：

```
L_consistency = Σ_k ( R_k - mean(R) )²
```

直接惩罚七维奖励的方差。如果某几维奖励很高、某几维很低，这个项会很大，逼着优化别"牺牲定位换分类"。

> 为什么奖励里已经有 `-var(R)`，还要单独一个 `L_consistency`？两者功能重叠但作用位置不同：`α` 作用在奖励内部（softmax 归一化之后、反号之前），`γ` 作用在损失层。工程上可以二选一调参，保留两个是为了可独立消融。

## 4. 可学习维度权重与自适应更新

`HybridRewardTrainer.__init__`（`hybrid_reward_trainer.py` 第 86 行）声明：

```python
self.dim_weights = nn.Parameter(torch.ones(7) / 7)
```

并被加进优化器参数（与模型参数一起，用 AdamW 优化）。

**自适应更新**（`_update_adaptive_weights`，第 355 行）：每 `weight_update_freq=5` 个 epoch，看近 5 个 epoch 每维奖励的变化速率：

```
rate_k = | R_k(最近) - R_k(5 epoch 前) | / 5
w = softmax(rate)        # 收敛越慢的维度权重越高
```

直觉：**"学不动的维度"得到更大权重**，把优化火力往短板倾斜，防止某些维度（尤其关键类）被平均精度淹没。

## 5. 训练循环

`HybridRewardTrainer`（第 37 行）是单机版的完整训练器。每个 step（`train_step`，第 122 行）走一遍：

```
1. 数据增强 → 前向 → _normalize_predictions 补齐字段
2. compute_all  → 得到 7 维奖励
3. total_loss    → 得到 total / detection / scalar / consistency
4. backward → clip_grad_norm(1.0) → optimizer.step
```

每个 epoch 结束时（`fit`，第 276 行）：`scheduler.step()`（CosineAnnealing）、`validate()`、记录 `dim_history`、到周期触发自适应权重更新。

> 关键点：7 维奖励和 `dim_weights` **都参与反向传播**——奖励通过 `L_scalar`/`L_consistency` 把梯度送进模型 logits/boxes，`dim_weights` 则被奖励本身优化。这就是"混合"的含义：**模型 + 维度权重一起学**。

## 6. 超参数表（单机版默认值）

| 参数 | 默认 | 含义 |
|---|---|---|
| `learning_rate` | 0.001 | AdamW 学习率 |
| `weight_decay` | 1e-4 | 权重衰减 |
| `lambda_miss` | 1.5 | 漏检惩罚系数 |
| `lambda_fp` | 1.0 | 误检惩罚系数 |
| `beta` | 0.1 | 奖励项权重 |
| `gamma` | 0.05 | 一致性项权重 |
| `alpha` | 0.3 | 标量奖励内一致性系数 |
| `weight_update_freq` | 5 | 自适应权重更新周期 |
| `num_classes` | 18 | 类别数（合并后） |

> 注意：这是**单机版** `HybridRewardTrainer` 的超参数。RT-DETR 的 Layer-1 注入用 `β=0.5`（见 [04](04-奖励注入与GRPO.md)），两者 `β` 含义相同但默认值不同，不要混用。
