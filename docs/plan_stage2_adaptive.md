**日期**：2026-10-20 ｜ **状态**：2B-1 已完成（有结果）；2A UW 三种子链运行中（`scripts/stage2_uw_seeds.sh`，后台，约 4.5–5h，预计 19:00 前后完成）；2B-2 脚本设计中
**触发**：阶段 1.3 七维奖惩强基线重测全负（mean −0.015~−0.029 + GRPO 崩溃；Layer-1 三种子 CONFIRMED_NEGATIVE）后，用户提出两个正交方向：① 用 Uncertainty Weighting / GradNorm 自动学习 cls↔reg 损失权重，替代手动静态奖惩；② 转向推理侧结构化优化（校准 + 贝叶斯不确定性）加固告警决策。

**预登记的混杂说明（结果解读前约定）**：UW 实现采用**尺度保持归一化**——初始 w=1:1 与对照逐位相同，任意时刻总损失 `w_cls·L_cls + w_reg·L_reg = L_cls + L_reg` 恒等于默认值，**唯一实验变量是 cls:reg 比值**（稳态 = L_reg:L_cls），"等效学习率"混杂按设计消除。GradNorm 每步同样归一化，可作为"不同均衡规则"的对照臂（若启动）。

## 0. 提案与项目自身证据的对账（先证伪，再设计）

### 0.1 训练侧（UW / GradNorm）——低先验，但方向从未被隔离检验

支持检验的三点理由：

1. **基础损失权重方向是空白**。既有全部负结果（R2 severity / B pos / NWD / Layer-1 / GRPO）都是在默认损失之上**叠加**奖励或**类条件**重加权，从未改变 ultralytics 的基础增益。而 `models/utils/loss.py` 的默认增益是 `class×1, bbox(L1)×5, giou×2`——**回归臂比分类臂重 5–7 倍**。官方指标 mean(mAP@0.1/0.3/0.5) 有 2/3 权重在 IoU 0.1/0.3 档，低 IoU 下定位几乎免费、**分类质量主导**。
2. **计算开销近零**。UW 是每步两次标量解析更新；GradNorm 约 2× 反传。5ep/臂的协议下完全可负担。
3. **零和结构预测它不会改善 mean**——这本身就是值得报告的阴性结果：若召回-精度零和（见 0.3）是分数不可分性造成的，则任何重平衡都无法打破，UW 的负结果将从"又一次失败"升级为"权重方向已被隔离检验并证伪"的证据链一环。

**假设方向的实测修正（2026-10-20，经两个实现 bug 修复后的全量数据验证）**：UW 的均衡由**损失值**而非增益决定。开发期发现并修复两个实现 bug（均已留档）：① `w=exp(+lv)` 符号错误（Kendall 公式要求 `exp(−lv)`，正指数构成正反馈 runaway，双臂饱和于截断上限）；② 更新项误用归一化后的权重——双 lv 钉住截断 +2.0 后 wu 相等、归一化产出**精确 1:1**，臂静默退化为均匀对照（全量数据诊断在 step 900 实证：lv=(2.0,2.0)、w=(1.0000,1.0000)）。修复版：更新项用未归一化 `wu=exp(−lv)`（稳态 wu=1/L），应用权重尺度保持（总损失恒等于默认）。**全量数据诊断验证（seed 42，900 步）**：w 从 1:1 单调收敛到 (1.91, 0.73)（比值 2.6，朝稳态比 L_reg/L_cls≈3.2 逼近），lv 在自然稳态轨迹、无钉住。即 UW 学到的方向是**升分类权**——与"官方指标 2/3 权重在分类主导的低 IoU 档、默认回归增益过重"的朴素假设**一致**，且与 R2 severity（类条件回归加权，历史最负臂 −0.023）**方向相反**：UW 转正将与 R2 形成"全局 vs 类条件回归加权效果相反"的对照。先验中性偏高。权重轨迹本身仍是可发表的诊断证据（收敛显著偏离 1:1 即"默认增益对本指标欠优"的实证）。

反对检验的一点（诚实记录）：**R2 severity（类条件 box 臂加权）在强基线上是最负的非 GRPO 臂（−0.0231），crit_R 0.730↔crit_P 0.576**。它与"重加权损失臂"同族，只是条件在类别而非全局。全局权重方向有理由比它更平，但没有保证。

### 0.2 推理侧校准——已有实测：解释性胜利，不是性能杠杆

今天完成的校准审计（`scripts/eval_calibration_audit.py`，957 张 val、287,100 条预测、TP/FP 标签用 r_curve 同口径匹配）：

| 指标（运行区域 conf≥0.05） | tianchi18_full (0.572) | mosaic1280 (0.635) |
|---|---|---|
| ECE 原始 | 0.1055 | 0.1116 |
| ECE 全局温度缩放（5 折交叉拟合） | **0.0029** | **0.0028** |
| ECE 按族条件 TS | 0.0030（无增益） | 0.0029（无增益） |
| ECE 按尺寸条件 TS | 0.0032（无增益） | 0.0029（无增益） |
| TP/FP 可分性 AUC | 0.763 → TS 后 **0.763（严格不变）** | 0.823 → **0.823** |
| 关键类 pooled AUC | 0.812 | 0.871 |
| 关键类 TP 置信度中位数 | 0.45 / 0.41 / 0.45 | 0.75 / 0.47 / 0.59 |

三条结论：
- **失准是真实的且巨大**：conf 0.5–0.6 的预测实际正确率仅 0.17–0.21（过信 2–3 倍）；ECE ≈ 0.11。单个全局温度（拟合 T≈0.6，即分数分布被压缩、真缺陷中位置信度仅 ~0.45）即可把 ECE 打到 0.003。
- **校准不改变可分性**（单调变换，AUC 严格不变）——论文 4.12"真检与误检无法按置信度分离"从断言升级为量化命题：原始置信度 AUC 0.76–0.82，任何单调重校准都不可能超越；告警评分 0.9399 的 AUC 来自结构而非校准。
- **条件校准（族/尺寸）无增益**——失准是全局同质的。用户提案中的"结构化校准"一支已被数据排除；剩余杠杆是**集成不确定性**（2B-2）。

## 1. 阶段 2A：训练侧自适应损失加权

### 1.1 协议（与强基线对照逐项一致，唯一变量=损失权重机制）

| 项 | 值 |
|---|---|
| 起点权重 | `runs/rtdetr/tianchi18_mosaic1280/weights/best.pt` |
| epochs / batch / imgsz | 5 / 4 / 1280（方形 letterbox） |
| lr0 / lrf / warmup | 1e-4 / 0.01 / 3.0 |
| amp / rect / optimizer | **False** / False / auto(MuSGD) |
| seed | 42（+123、2024 复测） |
| 对照 | `strong_r2_uniform` mean **0.6158**（crit_R 0.626 / crit_P 0.637）；种子对照 0.6132 / 0.6123 |

### 1.2 UW 臂（Kendall et al., CVPR 2018, arXiv:1705.07115）

- 两个可学习 log-方差参数（cls / reg），初值 0 → 权重恰为默认 1:1，**init 与对照轨迹完全一致**。
- 每步解析更新（无需额外反传）：`lv_i -= lr_uw · (1 − w_i·L_i)`，`w_i = exp(−lv_i)`，lv ∈ [−2, 2] 截断（w ∈ [0.14, 7.4]）防塌缩。
- reg 组 = 所有 `*bbox*`/`*giou*` 键（含 aux/dn 变体）；cls 组 = 所有 `*class*` 键。
- 轨迹记录：每 50 步写 (step, w_cls, w_reg, ratio, L_cls_ema, L_reg_ema) 到 JSON；`ADAPTIVE_DEBUG=1` 环境变量可开每步诊断输出（冒烟调试用）。

### 1.3 GradNorm 臂（Chen et al., ICML 2018, arXiv:1711.02257）

- trunk = encoder（HybridEncoder，最后共享层近似）；每步两次 `autograd.grad` 取各组梯度范数 G_cls/G_reg（反传开销 ≈2×，`allow_unused=True` 不过 .grad，安全）。
- 乘性更新 `w_i *= (Ḡ/G_i)·(r_i/r̄)^α`，α=1.0，lr=1e-3，更新后归一化 Σw=2；r_i = L_i/L_i(0)（逆训练速率）。
- **仅在 UW 有信号或需完整对比时启动**（预算见 1.5）。

### 1.4 预承诺判定标准（阶段 1.3 同规矩）

- **转正**：种子平均官方口径 mean > 0.6158 + 0.005 **且** crit_R 不降（>0.626−0.01）。
- **零和识别**：若 crit_R 升 >0.02 但 crit_P 降 >0.02（对照 crit_P 0.637），判"历史零和复现"，不计转正。
- **复测规矩**：单种子结论无效；3 种子中 ≥2 正才允许声称；Δmean 报告均值±标准差（历史种子噪声 0.0093）。
- **权重轨迹判据**（UW 独有）：若 w_cls/w_reg 收敛显著偏离 1（如 cls 权重 >1.5），记录为"默认增益对本指标欠优"的证据（即使 mean 未转正）。

### 1.5 预算

- UW 3 种子 × 5ep ≈ 3 × 95 min ≈ **4.8 GPU-h**（今晚后台链）。
- GradNorm（若启动）3 种子 ≈ 2× ≈ **9.6 GPU-h**。
- 评测：每臂 `eval_multIou.py` 官方口径 + crit 分解。

## 2. 阶段 2B：推理侧结构化优化

### 2B-1 校准（已完成，见 0.2）

- 交付：`scripts/eval_calibration_audit.py`，存档 `runs/calibration/audit_{tianchi18,mosaic1280}.json`。
- 论文用途：4.12 增加"校准审计"段（ECE 0.106→0.003 / AUC 不变 0.763/0.823 / 条件校准阴性），把"不可按置信度分离"升级为定量命题。

### 2B-2 集成不确定性（贝叶斯路线的实用替代，已完结：阴性）

- 依据：MC Dropout（Gal & Ghahramani, ICML 2016, arXiv:1506.02142）在 RT-DETR  decoder 无 dropout 不可用；深度集成（Lakshminarayanan et al., NIPS 2017, arXiv:1612.01474）是本架构下唯一现实的认知不确定性来源。
- **免费素材**：3 个既有均匀对照 checkpoint（`strong_r2_uniform` + `l1_seed{123,2024}_ctl`，同起点不同种子）构成现成 3 成员集成；UW 链完成后另有 3 个协议一致的成员。
- 指标：① 集成均值分数的 TP/FP AUC vs 单模型；② 分歧度（std）作为"送复核"闸门的 FPR@固定召回；③ 三档告警（停机/复核）的 FPR 对比 4.12 的七维评分基线（AUC 0.9399）。
- 判定：若分歧闸门在固定召回下 FPR 显著低于分数阈值（如 −20% 相对），推理侧结构化优化成立，进入论文 4.13。
- **实测结果（2026-10-21 02:50 完结，论文 4.15）**：两套集成——ctl3（3 成员）与 uw4（UW 四种子，协议匹配）——均**未达到**预登记标准。集成召回 0.9570（成员 0.9475–0.9538，提升 +0.004~0.007，经典集成增益）；AUC(mean_conf) 0.9699/0.9773、AUC(std_conf) 0.9650/0.9792；**分歧度与 TP 正相关**（TP 簇 std 0.157/0.121 vs FP 簇 0.004/0.002，40–65×），误检簇多为单成员突发（std≈0）；t=0.25 工作点加 std≤0.20 闸门：ctl3 召回 −61% 而 FPR 仅 0.0009→0.0006、uw4 召回 −48% 而 FPR 0.0002 不变——匹配召回下纯分数阈值不劣于门控。90%+ GT 被全体成员一致触发（878/953、863/953）→ 同起点深度集成是置信度平均而非贝叶斯模型平均，不含正交信息。存档 `runs/calibration/ensemble_{ctl3,uw4}.json`，链 `scripts/stage2_e3_ensemble.sh`（task hl859k）。
