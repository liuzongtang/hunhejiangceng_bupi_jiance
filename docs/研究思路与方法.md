# 研究思路与方法

## 一、研究思路

本项目遵循"构建基线 → 诊断瓶颈 → 定向干预 → 闭环落地"的递进式研究思路，以实验数据驱动研究走向，避免盲目调参。

**（一）构建基线。** 以 RT-DETR-L 训练 20 类 Tianchi 检测器，建立 mAP50 = 0.594 的精度基准与逐类性能画像，作为后续一切干预的对照参照。

**（二）诊断瓶颈。** 通过逐类 mAP、混淆矩阵与裁剪图复核，定位关键缺陷召回不足的根因——是类别稀有度、训练不足，还是视觉同源/标签噪声？以证据而非假设驱动下一步。

**（三）定向干预。** 分层实施干预并逐一验证：Layer-1 奖励注入（把工业代价写入损失）、Layer-3 GRPO（奖励引导的强化学习）、过采样与置信度校准等，全部以严格 A/B 对照验证每种干预的真实效果。

**（四）闭环落地。** 将"检测—告警—停机"闭环中的安全兜底落到告警层，并通过系统集成与测试保障可行性。

## 二、研究框架

```
数据层   Tianchi 20 类数据集（预处理、1280 拉伸方图）
   ↓
模型层   RT-DETR-L 检测器（PyTorch / ONNX 双后端）
   ↓
奖励层   七维混合奖惩（D01~D07，可微）→ L_total = L_det + β·L_scalar + γ·L_consistency
   ↓
诊断层   逐类 mAP + 混淆矩阵 + 双向性判定 + 裁剪复核
   ↓
告警层   effective_alert_severity() 易混淆类保守升级
   ↓
应用层   FastAPI + WebSocket + 中文看板 + 边缘部署
```

## 三、具体方法

**（一）检测器训练。** 采用 ultralytics RT-DETR-L，输入 1280 拉伸方图（BGR→RGB、/255，无 ImageNet 均值方差），一对一匈牙利匹配、免 NMS；输出 `(1, 300, 6)` 归一化 `[cx, cy, w, h, score, class]`。

**（二）七维奖励可微化。** 将奖励中的硬决策（argmax、集合成员、硬 IoU 阈值）替换为 softmax/sigmoid 软指示，使奖励对模型参数可微、能直接反传进模型，而非仅调节维度权重。

**（三）奖励注入（Layer-1）。** `RewardRTDETRDetectionLoss` 在损失中追加 `loss_reward = -β·mean(R)`，与检测损失线性叠加，实现零侵入的监督增强；`include-misses` 参数将漏检关键类的最佳备用查询纳入惩罚。

**（四）GRPO（Layer-3）。** 向内容查询注入高斯噪声 `z = mean + std·eps`，以**似然比得分**（而非重参数化）估计策略梯度，避免梯度恒为零的陷阱；组内相对优势采用 eps 下限 + clip 防优势爆炸，KL 锚定冻结参考策略防策略坍塌；`beta_reward` 通道回传可微奖励以驱动被 detach 的查询均值。

**（五）标签噪声诊断。** 以混淆矩阵判断混淆是否**双向**（双向即标签噪声特征，单向为系统偏差）；合并视觉同源类重新评测召回，量化"合并收益"（纬缩+粗纬 0.40→0.88）。

**（六）告警兜底。** `CONFUSABLE_HIGHER_IMPACT` 映射 + `effective_alert_severity()`，以 `max(原级别, 易混淆高影响类级别)` 作为告警级别，存储规范级别不变、升级级别独立落库可审计。

## 四、研究逻辑与方法应用流程

问题提出（关键类召回不足）→ 基线画像（逐类 mAP 长尾）→ 根因假设（稀有度 / 训练不足 / 标签噪声）→ 分层干预与 A/B 验证（奖励 / GRPO / 校准 / 过采样）→ 结论判定（标签噪声天花板）→ 转向数据层（合并 / 重标注）+ 告警层（保守升级）→ 系统集成与测试落地。

这一流程的关键在于：**每一步都以可量化的证据（mAP / 召回 / 混淆矩阵）作为下一步的决策依据**，使研究走向可追溯、可复现，避免"为调参而调参"。
